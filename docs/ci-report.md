## Два новых сценария
1. `test_negative_elapsed` — проверяет, что отрицательное время вызывает `ValueError`
2. `test_unknown_priority` — проверяет, что неизвестный приоритет ("urgent") вызывает `ValueError`

Итого: 8 тестов проходят на обеих версиях Python.

## Что автоматическая проверка пока не покрывает
- Не проверяются другие типы входных данных (например, строка вместо числа)
- Не проверяются версии Python вне матрицы (3.10, 3.13)
- Не проверяется поведение при очень больших числах
- Нет тестов на производительность
